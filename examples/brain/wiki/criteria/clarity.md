# Clarity

Can the reader follow the argument without re-reading. In practice, long sentences pull this score down even when the argument is sound.

Sources: raw/criteria/rubric-v1.md, raw/assessments/essay-001.md, raw/assessments/essay-002.md, raw/assessments/essay-003.md, raw/feedback/reviewer-note-2026-08.md

## Rubric text
5: every sentence does work. 3: main line clear, some paragraphs wander. 1: reader cannot say what is argued.

## Examples by score
- **4**: [essay-001](../cases/essay-001.md). Thesis in paragraph one, returned to; one paragraph drifts.
- **3**: [essay-002](../cases/essay-002.md). Clear thesis, two paragraphs repeat each other, long sentences.
- **2**: [essay-003](../cases/essay-003.md). Argument changes between paragraphs 1 and 5; terms undefined.

## Edge cases
- Repetition across paragraphs costs one point (essay-002), drift within one paragraph costs one point (essay-001).
- Sentence length is not in rubric v1 but reviewer B applies it. Flagged for rubric v2 in the 2026-08 calibration note.
