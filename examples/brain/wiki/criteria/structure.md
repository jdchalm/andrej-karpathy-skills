# Structure

Does the shape of the essay help: an intro, body sections that build in order, a conclusion that adds something.

Sources: raw/criteria/rubric-v1.md, raw/assessments/essay-001.md, raw/assessments/essay-002.md, raw/assessments/essay-003.md

## Rubric text
5: clear intro, body sections that build, conclusion that adds. 3: identifiable sections, weak transitions. 1: one block.

## Examples by score
- **5**: [essay-001](../cases/essay-001.md). Three body sections each on one benefit; conclusion proposes a pilot.
- **3**: [essay-002](../cases/essay-002.md). Sections exist, transitions abrupt, conclusion restates intro.
- **2**: [essay-003](../cases/essay-003.md). No conclusion; body sections in no clear order.

## Edge cases
- A conclusion that only restates the intro reads as 3, not 5, even with clean sections (essay-002).
- Missing conclusion plus unordered body is 2, not 1: sections were still identifiable (essay-003).
